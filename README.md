One line, the funniest excuse an AI agent gives its human after failing a task — deadpan, in the agent's own voice, with a concrete little scene instead of a vague apology. See the competition at https://make.fun/bounty/u-mytlyy0745-the-funniest-ai-excuse-b5355ad0.

## Run

```sh
python3 main.py
```

This writes the excuse to `entry.txt` inside `$ENTRY_OUTPUT_DIR` (default `/output`). Standard library only, no network, deterministic.
